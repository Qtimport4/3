Proyecto 1: Sistema de Videovigilancia Exterior

Este proyecto consiste en la instalación de un sistema de videovigilancia exterior mediante cámaras de seguridad, orientado a la supervisión de espacios abiertos como calles, accesos y perímetros.

Instalación

Se implementan cámaras tipo domo con capacidad de movimiento (PTZ) y cámaras fijas, considerando factores como altura, ángulo de visión y condiciones climáticas.

Infraestructura

El sistema se conecta a equipos DVR/NVR para el almacenamiento de grabaciones y monitoreo en tiempo real.

Acceso Remoto

Se habilita acceso remoto desde dispositivos móviles y computadores para la supervisión continua.

Seguridad

La solución permite mejorar la seguridad del entorno, facilitando la detección de incidentes y el control de zonas estratégicas.
